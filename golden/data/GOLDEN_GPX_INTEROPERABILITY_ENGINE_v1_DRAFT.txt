PORT CONTRACT
parse(UTF8 XML, limits) -> ParseResult(document, warnings, originalPointCount)
export(GpxDocument, options) -> UTF8 XML
simplify(points, toleranceMeters, protectedIndices) -> ordered points
Document: tracks/segments, routes, waypoints, metadata, source provenance.
Point: WGS84 lat/lon, optional altitudeMeters, optional UTC timestamp, name.
Explicit distinction: raw routes are NOT verified routable road paths.

INVARIANTS
- Namespace-aware GPX recognition; reject wrong root and malformed XML.
- Reject non-finite/out-of-range latitude [-90,90] / longitude [-180,180].
- No DTD/external entity resolution, network, path expansion or unbounded inputs.
- Bound file bytes, number of points and parsing work (CamperBoss 5MB/10k points donor policy).
- Preserve point order, segment boundaries, start/end and optional elevation/time.
- GPX UTC/offset round-trip stable at declared precision, missing fields remain missing.
- XML escaping, stable format version, no fabrication of routes on invalid input.
- Simplification is OPT-IN and must preserve protected waypoints and segments.
- Unsupported extensions and lossy fields reported, not silently accepted.
