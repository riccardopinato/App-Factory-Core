INVARIANTS
- Deterministic rule order, one action per rule, idempotent repeated events.
- Disabled rules and already-satisfied actions are safe no-ops.
- A rule-applied mutation does NOT trigger infinite recursive re-evaluation.
- Deleted content, missing target collection or forbidden scope never mutated.
- Bound rule count, chain depth, log count and input lengths.
- Unrecognized action/schema/trigger fail closed; no arbitrary user code.
- Execution log/fingerprint must survive restart if durable side effects exist.
- Remote orchestration/replay remains under GOLDEN_EVENT_DRIVEN_RECONCILIATION.
- No cloud service or AI requirement.
